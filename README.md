# DonutSMP Utility Mod

A utility mod for Minecraft with toggleable features

## Features

- Toggleable creative flight
- Speed and jump controls
- Fullbright/Night Vision
- Fast mining
- Item spawning

## Requirements

- Minecraft 1.20.4
- Fabric Loader 0.14.0 or higher
- Fabric API

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/donutsmp-utility-mod/releases).
2. Place the mod file in your Minecraft mods folder.
3. Launch Minecraft with the Fabric profile.

## Usage

1. Launch Minecraft with the mod installed.
2. Press the 'R' key to open the DonutSMP Utility GUI.
3. Use the buttons in the GUI to toggle the desired features.

## Configuration

The mod does not have a configuration file. All features are toggled through the in-game GUI.
